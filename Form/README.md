# React Hook Form Registration

A simple **Register Form** built with **React Hook Form** and **Yup validation**, with a modern and beautiful design.

---

## Features

- **Full Name**: Required, minimum 3 characters  
- **Email**: Required, must be a valid email format  
- **Password**: Required, minimum 8 characters, must include at least 1 number  
- **Confirm Password**: Required, must match Password  
- **Terms & Conditions**: Checkbox must be checked  
- Error messages appear under each field  
- Form is fully **centered** with a **blue-to-cream gradient background**  
- **Submit** button is large, yellow by default, turns green after successful submission  
- Form data is logged to the **console** on successful submit
